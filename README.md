# Bank System (Procedural C++)

## Description 
Console-based client managment system. Supports:
- Show all clients
- Add new client
- Delete client
- Update client information
- Find client by Account Number

  ## Concepts Used
  - Procedural programming (functions only, no OOP)
  - File I/O (text files for data storage)
  - Structured menu system
  - Input validation

  ## How to Run

  ### Compile:
  ```bash
  g++ BankSystemProject.cpp -o bank
  ./bank
